## 17번

**정답:**

1. 가로 320px, 세로 240px의 비디오 플레이어를 생성하고 `controls`와 `autoplay`를 설정한다.
2. MP4 파일을 지원하면 `bear.mp4`를 재생하고, 지원하지 않으면 `bear.ogg`를 재생한다.
3. `<video>` 태그를 지원하지 않는 경우 대체 텍스트를 출력한다.
